# Ortodont Pro — сайт стоматологии (Актобе)

Отдельный проект на базе дентал-прототипа ЭМАЛЬ. Свой репозиторий и свой проект на Vercel — не связывать с прототипом.

Next.js 16 (App Router), TypeScript, Tailwind CSS v4, GSAP + ScrollTrigger и Lenis.

```bash
npm install
npm run dev
```

Проверка перед выкладкой:

```bash
npm run typecheck
npm run build
npm run start
```

Запускайте команды из папки проекта: корень для Turbopack задан в `next.config.ts` через `process.cwd()`. Без него `package-lock.json` в родительской папке сдвигает корень, пути начинаются с кириллицы, и Turbopack падает с паникой `not a char boundary`.

## Что заменить перед запуском

| Что | Где |
|---|---|
| Бренд, домен, город, контакты, часы, реквизиты, лицензия, рейтинг и статистика | `src/content/site.ts` |
| Пометки «демо» на всём сайте | `isDemo: false` в `src/content/site.ts` |
| Прайс | `src/content/prices.ts` |
| Врачи: ФИО, образование, сертификаты | `src/content/doctors.ts`, фото в `public/images/doctors/` |
| Работы до/после | `src/content/cases.ts`, снимки в `public/images/cases/` |
| Отзывы из 2ГИС и Яндекс | `src/content/reviews.ts` |
| Вопросы и ответы | `src/content/faq.ts` |
| Тексты секций главной | `src/content/copy.ts` |
| Описания услуг | `src/content/services.ts` |
| Карта | `mapEmbed` в `src/content/site.ts`, ссылка на iframe 2ГИС или Яндекс Карт |

Правило портфолио: нет реальных фото пациента — нет блока. Пока массив `cases` пуст, на сайте нет блока «Работы», страницы `/cases` и пункта в меню. Как только добавите первую работу с настоящими снимками, всё появится автоматически. Стоковые улыбки подставлять нельзя.

## Заявки

Скопируйте `.env.example` в `.env.local` и заполните:

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather;
- `TELEGRAM_CHAT_ID` — чат, куда приходят заявки.

Без этих переменных форма работает и ведёт на `/thanks`, но заявка никуда не уходит: в логе сервера будет предупреждение. Перед запуском обязательно заполните их.

Лимит запросов хранится в памяти процесса: 5 заявок с IP за 10 минут. На нескольких инстансах или в serverless он считается отдельно для каждого экземпляра.

## Шрифты

Лежат в `public/fonts`, подключены через `next/font/local` в `src/lib/fonts.ts`.

| Шрифт | Роль | Ограничения |
|---|---|---|
| Pribylskaia | заголовки, крупные цифры | только капс; нет `· → ↗ ← × ₸ ★` |
| Golos Text | текст и интерфейс | OFL, файлы 400/500/600 |
| JetBrains Mono | цены, сроки, рейтинг | OFL, файлы 400/500; нет `₸`, знак берётся из Golos Text |

Стрелки и звёзды — SVG из `src/components/ui/Icons.tsx`, а не символы шрифта.

К Pribylskaia приложена только строка копирайта, без условий лицензии: перед коммерческим запуском уточните их у автора.

## Анимации

Секции остаются серверными компонентами: анимации вешаются на data-атрибуты в `src/hooks/useReveal.ts`. Первый экран (`h1`, подзаголовок, кнопки) и прелоадер анимируются чистым CSS, чтобы всё работало без ожидания JS. Прелоадер показывается при каждой полной загрузке страницы, при переходах внутри сайта его нет.

| Атрибут | Эффект |
|---|---|
| `data-split` | Blur Reveal по буквам для заголовков |
| `data-reveal` | появление снизу, с `data-blur` ещё и из размытия |
| `data-reveal-group` + `data-reveal-item` | Blur In для карточек, каскадом |
| `data-count` | Number Roll |
| `data-float`, `data-parallax` | парение и параллакс зуба |

Запускать появления только через `playOnEnter` из `src/lib/gsap.ts`. `once: true` в ScrollTrigger использовать нельзя: при открытии страницы не сверху (якорь, перезагрузка) он роняет страницу.
